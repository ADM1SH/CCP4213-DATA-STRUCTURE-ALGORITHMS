# CCP4213: Data Structures & Algorithms

## Course Overview
This repository contains coursework, labs, and project files for the Data Structures and Algorithms course. It covers foundational topics essential for efficient software development.

## Key Topics
- **Searching & Sorting**: Implementations of various algorithms like Binary Search.
- **Linked Lists**: Node-based storage structures.
- **Stacks & Queues**: Linear data structures for LIFO and FIFO operations.
- **Trees & Graphs**: Complex non-linear data structures.
- **Hashing**: Efficient data retrieval techniques.

## Structure
- `lab/`: Weekly laboratory exercises.
- `project/`: Major course project source code.
- `Revision_Master/`: Consolidated notes and practice for exams.
- `midtermLockin/`: Preparation materials for the midterm examination.
